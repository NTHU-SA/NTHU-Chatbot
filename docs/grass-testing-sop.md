# 草地現場測試 SOP：校準 → iPhone 連線 → 測試 → 收尾

[回到 README](../README.md)

**文件狀態：通用草稿，尚未通過設備專屬驗收。**

本文件適用於需要校準並以 iPhone 操作或讀取資料的設備。設備種類、型號、App 與連線協定尚未提供，因此本文件不指定校準動作、數值、按鍵位置或運動控制命令。原廠手冊與現場安全規範優先於本文件。

若設備會移動、旋轉、飛行或有其他危險機構，必須由合格操作人員補齊設備專屬安全流程；未完成前，只能做不啟動危險機構的連線與靜態檢查。本 SOP 不構成飛行、刀具運轉或其他危險作業的操作授權。

## 1. 測試前必填

| 項目 | 本次設定 |
| --- | --- |
| 設備名稱／型號／識別標籤 | 待填 |
| 原廠手冊版本與校準章節 | 待填 |
| 韌體版本／App 名稱與版本 | 待填 |
| iPhone 型號／iOS 版本 | 待填 |
| 連線方式 | 待確認：藍牙／設備 Wi-Fi／共享區域網路／USB |
| 測試目的與預期結果 | 待填，需可量測 |
| 校準項目及成功判定 | 待填，引用原廠規格 |
| 場地、日期、操作人員、觀察人員 | 待填 |
| 天候、草況與原廠環境限制 | 待填 |
| 允許範圍、停止方式與緊急處置 | 待填 |
| 通過門檻 | 待填：誤差、延遲、連線穩定度或其他適用指標 |

**放行條件：** 安全、校準與通過門檻不得留白後直接進入正式測試。無法確認的項目標示「未確認」，不要視為通過。

## 2. 準備設備與場地

- [ ] 備妥設備、iPhone、所需線材／轉接器、備用電源、原廠手冊與紀錄表。
- [ ] 電池電量足以完成測試並安全收尾；採用原廠要求，不自行設定通用百分比。
- [ ] 確認設備沒有鬆脫、損壞、異常發熱或電池膨脹；有異常即停止。
- [ ] 韌體與 App 版本固定並記錄；不要在正式測試中途更新。
- [ ] 確認場地使用許可、範圍邊界、旁人與動物隔離及現場通訊方式。
- [ ] 記錄風、雨、溫度、草高、乾濕與坡度；確認符合設備限制。
- [ ] 避開積水、坑洞、石塊、金屬雜物與其他影響測試的障礙。
- [ ] 依原廠要求選擇校準位置。若要求水平、穩固或無磁性干擾，使用合規的平台；不要直接把鬆軟草地當成水平基準。
- [ ] 在不啟動危險機構的狀態下，確認停止方法與安全狀態顯示；涉及動態驗證時另依設備專屬流程。

## 3. 校準

### 3.1 判斷是否需要校準

1. 查閱原廠手冊，確認本次需要校準哪些項目，以及搬運、換場地、更新韌體或更換配件後是否需重做。
2. 記錄目前校準狀態與設定；不要因為「到了現場」就重新校準所有感測器。
3. 檢查校準的前置條件：安裝姿態、水平基準、暖機時間、溫度、外部干擾與供電狀態。
4. 若校準需由 App 發起，先完成第 4 節連線，再返回本節；若可獨立校準，按原廠順序操作。

### 3.2 執行與確認

1. 讓設備進入原廠指定的安全校準狀態。
2. 按原廠流程逐項校準；僅執行該型號要求的動作，不套用其他設備的旋轉或移動方式。
3. 過程中保持要求的姿態與環境，避免觸碰、震動或中斷供電。
4. 記錄開始／結束時間、結果、錯誤碼與校準前後數值（如有）。
5. 按原廠規定儲存、套用或重新啟動；確認校準結果已保存。
6. 以原廠指定的已知基準或檢查方法驗證，不只看「成功」提示。
7. 驗證不符規格時，先檢查環境及前置條件；排除原因後依原廠規定重試。持續失敗則停止，不帶著失敗結果進行正式測試。

**本階段完成條件：** 所需校準項目均通過，獨立驗證符合規格，結果可追溯。

## 4. iPhone 連線

只執行本設備實際支援的分支。不要把「iPhone 顯示已連線」等同於「App 已連上正確設備」。

### 4.1 共通準備

1. 確認 App 為原廠或專案指定來源，版本符合設備要求。
2. 開啟 App，依功能需要授予藍牙、區域網路或其他權限；不為排錯一律開啟所有權限。iOS 的設定位置可能隨版本不同。
3. 確認設備正在可連線狀態，並比對設備名稱與識別標籤，避免連錯現場其他設備。
4. 若需要帳號登入，完成登入，但不把密碼、token 或個人資料寫入測試紀錄。

### 4.2 藍牙

1. 開啟 iPhone 藍牙，確認 App 的藍牙權限已允許。
2. 依原廠說明，在 App 內搜尋／連線，或在 iOS 設定中配對。部分 BLE 設備只在 App 內連接，不會列為系統已配對設備。
3. 若找不到設備，確認是否被其他手機占用、是否處於可發現狀態及是否在原廠距離限制內。
4. 連上後核對識別資訊，讀取狀態，確認資料持續更新。

### 4.3 設備提供的 Wi-Fi

1. 在 iPhone 的 Wi-Fi 設定中選擇原廠指定的設備網路。
2. 依原廠提供的方式輸入密碼；不要在紀錄或截圖中保留密碼。
3. 設備 Wi-Fi 可能沒有網際網路。先確認這是否為預期架構，不能單憑「無網際網路」判定設備故障。
4. 回到 App，依原廠設定連接；若需輸入位址，使用手冊或設備提供的實際位址，不猜測 IP 或連接埠。
5. 確認 App 有需要的區域網路權限，再驗證狀態與即時資料。

### 4.4 設備與 iPhone 使用同一區域網路

1. 確認設備與 iPhone 已接入指定網路，且該網路允許彼此通訊。
2. 若使用訪客網路，查明是否有用戶端隔離；不要自行放寬共用網路的安全設定。
3. 依 App 的探索功能或指定端點連線。
4. VPN 可能影響路由；僅在政策允許時做受控比較，記錄變更並在測試後恢復，不一律關閉。

### 4.5 USB／有線連線

1. 確認設備明確支援 iPhone、有線協定與本次 iOS 版本。
2. 使用規格相容、具資料傳輸能力的線材與所需轉接器，確認供電要求。
3. 依原廠順序插接並開啟 App；充電成功不代表資料連線成功。
4. 完成必要且來源可信的配件提示；出現不明安全警告或安裝要求時停止查證。
5. 核對設備資訊並確認資料持續更新。

### 4.6 連線驗收

- [ ] App 顯示的設備識別資訊正確。
- [ ] 狀態／時間戳記持續更新，不是快取或舊資料。
- [ ] 執行設備支援的唯讀查詢，結果與設備現場狀態一致。
- [ ] 觀察約定的時間，記錄斷線次數與恢復時間。
- [ ] 在設備安全狀態下檢查 App 切換及螢幕鎖定後的連線表現；不要預設背景連線一定受支援。
- [ ] 若測試需要前景持續操作，確認操作人員能保持 App 在前景；如調整自動鎖定，記錄並在結束後恢復。

**本階段完成條件：** 連線到正確設備、取得新資料且符合預先訂定的連線門檻。

## 5. 草地現場測試

### 5.1 靜態檢查

1. 將設備放置於原廠允許的位置，保持危險機構未啟動。
2. 核對校準狀態、供電、連線、錯誤提示與目前讀值。
3. 檢查草地是否遮擋感測器、散熱孔、天線或其他關鍵部位；是否會進水或造成設備失穩。
4. 比較已知基準與顯示值，確認沒有因換位置而失效。
5. 記錄靜態結果，通過後才進入下一階段。

### 5.2 正式測試

正式操作命令、運動範圍與安全程序必須由設備專屬文件補齊；未補齊則本階段不可執行。

1. 每輪開始前確認人員、場地、停止方式與設備狀態均可放行。
2. 第一輪採用原廠允許、風險最低的測試條件；確認正常後再按既定測試計畫擴展。
3. 每輪只改變一項測試條件，例如位置、草況或連線距離，以利比較。
4. 使用相同流程記錄預期值、實際值、時間與異常；重複次數由測試計畫預先規定。
5. 觀察人員持續監看設備與周圍，不只看 iPhone 畫面。
6. 每輪結束使設備回到原廠指定的安全狀態，再整理結果或修改設定。
7. 任何校準、韌體、App 或連線設定變更都要另記版本／條件，重新做必要驗收，不能混入原本基準。

### 5.3 立即停止條件

出現以下情況即按設備專屬安全停止流程處置；不要預設直接拔電或靠近設備是安全的：

- 人員或動物進入隔離區，或場地邊界無法維持。
- 設備不受預期控制、姿態不穩、卡住或動作異常。
- 操作所需連線中斷、資料停止更新或 App 無回應。
- 校準失效、故障提示或讀值超出允許範圍。
- 異常聲音、氣味、發熱、電池異常或進水。
- 天候或草地條件超出原廠限制。
- 剩餘電量不足以安全完成操作與收尾。

設備安全後保存紀錄，查明原因；不可因重連成功或重開機成功就直接視為可繼續。

## 6. 常見問題排查

| 現象 | 優先檢查 | 恢復條件 |
| --- | --- | --- |
| App 找不到設備 | 連線協定、權限、設備可發現狀態、其他手機占用 | 正確設備可識別，資料更新正常 |
| 已連 Wi-Fi，但 App 無資料 | 是否連錯網路、區域網路權限、實際端點、網路隔離 | 唯讀查詢與新資料驗收通過 |
| Wi-Fi 顯示無網際網路 | 是否本來就是設備專用本地網路 | 本地功能正常；若需雲端，另確認原廠支援架構 |
| USB 能充電但不能連線 | 是否支援 iPhone、線材資料能力、轉接器、供電 | App 能識別設備並持續收資料 |
| 校準一直失敗 | 基準面、干擾、安裝姿態、環境條件、原廠錯誤碼 | 校準與獨立驗證皆符合規格 |
| 鎖定螢幕後斷線 | App 是否支援背景運作、iOS／設備限制 | 明確記錄限制；依測試需求重新判定可否使用 |
| 戶外頻繁斷線 | 遮擋、距離、干擾、供電及所用協定 | 原因排除且連線驗收重做通過 |

一次只調整一個設定並保留前後結果。不要以關閉安全機制、略過校準或恢復原廠設定作為預設排錯方式。

## 7. 收尾與資料保存

1. 按原廠流程停止操作並確認安全狀態。
2. 保存與匯出本次結果，核對檔案可讀且輪次完整，再結束 App 或切斷連線。
3. 按原廠流程關閉設備及拆除線材，檢查草屑、濕氣、損傷與異常發熱。
4. 依原廠要求清潔、乾燥及存放，不自行以水沖洗或帶電拆卸。
5. 恢復為本次測試調整的 iPhone／網路設定。
6. 記錄結論：通過、未通過或中止；未執行的項目標示「未測」，不可當作通過。
7. 保存異常、排查結果與下次重測條件。截圖及匯出檔應遮蔽密碼、token 與不必要的個人資料。

## 9. 現場速查

**填妥設備與門檻 → 場地／設備安全確認 → 按原廠順序校準與連線 → 校準獨立驗證 → iPhone 即時資料驗收 → 草地靜態檢查 → 依設備專屬流程正式測試 → 安全停止 → 保存資料 → 清潔與恢復設定。**

任何前置驗收不通過，都不進入下一個正式測試階段。
